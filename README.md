# 🇸🇻 TripSv Web

Es la plataforma interactiva diseñada para la exploración turística en El Salvador. Permite a los usuarios descubrir destinos, visualizar rutas y planificar sus viajes a través de una interfaz web rápida, moderna y optimizada para dispositivos móviles.

**Nota:** Este repositorio contiene la versión web del ecosistema TripSv, desarrollada con un enfoque profesional y lista para producción.

---

## 🛠️ Tecnologías Utilizadas

*   **Core:** [React.js](https://reactjs.org)
*   **Framework de Desarrollo:** [Vite](https://vitejs.dev) (por los scripts de ejecución).
*   **Estilos:** CSS Modules / Tailwind CSS (menciona el que uses).
*   **Gestión de Estado:** Hooks (Context API o Redux).
